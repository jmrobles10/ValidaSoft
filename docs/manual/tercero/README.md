# Portal del tercero

Todo lo que hace el tercero: invitación, Mis empresas, revisión, documentos, ficha, cuentas designadas y avisos.

- [Acepta la invitación y completa tu información como persona jurídica](aceptar-invitacion-persona-juridica.md) — Tercero. Una empresa invita a un proveedor persona jurídica. Recibe el correo, entra con un código, acepta los textos legales, diligencia las seis secciones de «Mi información» y sube sus documentos hasta que su expediente pasa a revisión.
