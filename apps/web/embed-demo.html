Sesión delegada

En producción, el backend de este sistema firma la aserción X-Usuario-Delegado con su clave privada y pide la sesión en POST /api/v1/sesiones-usuario. Aquí lo hace el navegador con las credenciales de pnpm semilla:dev, solo para la demo.

No hay credenciales de demo. Levanta la API y ejecuta pnpm semilla:dev; luego recarga.
